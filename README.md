# Calculadora de Desconto de Frete
## Descrição do Problema
Calcular o valor final de uma encomenda considerando o peso e o desconto aplicado para clientes fidelizados.
## Requisitos
* Calcular frete base com base no peso (kg * 5.0)
* Aplicar desconto de 10% para clientes com mais de 1 ano
* Manter 2 casas decimais no resultado
## Exemplo de Uso
Entrada: peso=10, cliente_novo=False
Saída: 45.00
